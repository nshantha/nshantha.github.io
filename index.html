How I work

Habits I bring to every system I touch.

  1. Baseline before designing.Measure latency, error rate and volume in production before proposing a change.
  2. Write down the road not taken.Every decision record names the rejected alternative and the constraint behind it.
  3. Prove parity before cutover.Shadow mode, split feature flags, and a rollback plan for each named failure.
  4. Contain first, then fix the structure.Stop the bleeding quickly, then remove the cause so it can’t recur.
  5. Prove a fix is safe, not just fast.Show the output is identical before shipping an optimization.
  6. Alerts ship with triage steps.An alert nobody knows how to act on is only half an alert.
